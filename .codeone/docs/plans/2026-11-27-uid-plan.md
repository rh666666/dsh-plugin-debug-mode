## 任务 2：pairBlocks 按 uid 精确配对，与旧栈式分流

- [x] 改造 `pairBlocks()` 为两路配对，新增成功与失败用例。

**文件清单（修改）**

- `lib/scan.js`：`pairBlocks()`（第 162-206 行）按 `marker.uid` 是否有值分流
- `test/scan.test.mjs`：新增带 uid 的配对成功用例与失败用例，保留现有旧格式用例

**接口**

- 消费：`findMarkers()` 的返回值，`markers[].uid`
- 带 uid 路：按 `(hash, uid)` 分组；同组恰好一个 start 加一个 end、kind/hash 一致才成交；重复 start、重复 end、缺边、kind/hash 不一致进 `unresolved`，reason 写明具体情形
- 无 uid 路：原栈式逻辑逐字保留，kind/hash/缩进一致且块内无其他标记才成交
- 混用：两路各自产出 `blocks` 与 `unresolved` 后合并；带 uid 的标记不进入栈，无 uid 的标记不参与 uid 分组
- 产出：`{blocks: Array<{kind, hash, startLine, endLine, indent}>, unresolved: Array<{line, reason, text}>}`；`blocks` 元素结构不变，下游 `removeInternal()` / `classifyFile()` 无需改动

**新增用例**

- 成功：不同 uid 的两块嵌套；start/end 缩进不一致；同文件多块交错
- 失败：同 `(hash, uid)` 两个 start；只有 start 没有 end；start/end 的 uid 不同；start/end 的 hash 不同

**验证命令**

`node --test test/scan.test.mjs`
